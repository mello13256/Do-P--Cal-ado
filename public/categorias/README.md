# Imagens das categorias

Coloque aqui as fotos usadas nos cards de categoria da página inicial e
informe o caminho no campo `image` em `src/data/categories.ts`:

```ts
{ id: 'tenis', slug: 'tenis', name: 'Tênis', image: '/categorias/tenis.jpg', ... }
```

Recomendações: proporção **4:3**, aproximadamente 1200 × 900 px.
Sem imagem, o site desenha um placeholder com a identidade da loja.
